# Student Grade Tracker

A Java console application developed for the CodeAlpha Java Development Internship (Task 1).

## Description
This program enables educators to input and manage student grades dynamically, automatically computing essential class statistics including the average score, highest grade, and lowest grade.

## Features
- Dynamic entry for multiple student grades
- Automatic calculation of class average, highest, and lowest scores
- Clean, menu-driven console user interface built with Java

## Requirements & Implementation
- Accepts student names/IDs and numerical scores
- Calculates average, maximum, and minimum values
- Uses Java collections (`ArrayList`) for dynamic data storage

## Technologies Used
- **Language:** Java (JDK 8+)
- **IDE:** Eclipse IDE
